## Features

1. Dropdown showing all entire Tailwind colors pallet
2. Hovering a color swatch reveals a tooltip displaying the corresponding Tailwind color family, shade,  and  hex value.
3. Clicking a swatch dismisses the dropdown smoothly and then displays an alert showing the color name and hexadecimal value of the selection.
4. Custom actions can be assigned to the click feature.
4. Dropdown also dismissed by clicking target button again, any swatch clicked, mouseleave, or escape (when trigger button is focused)
5. Both  `mouseenter` or `click` variants
6. Both Landscape and Portrait variants (i.e. for  mobile screens).
8. Styling implemented entirely  with [Tailwind CSS](https://tailwindcss.com)
9. The Tailwind logo icon is passed into the `leftIcon` slot with appropriate styling classes applied.
10. Uses ClickDropdownMenu_A and HoverDropdownMenu_B hyperComponents (but without a caption)
11. The default slot for the dropdown component(s) receives a [PalletGrid](#palletgrid) custom component.   The PalletGrid takes an `orientation` prop which returns either a horizontally or vertically oriented grid of color swatches.  
12. The `duration` prop is set to '180ms' but can be any value.
13. A class of `.colorPallet` is added to the `buttonStyles` prop of the parent component (Click/HoverDropdown) so that the Hyperscript associated with each swatch can send a custom event which triggers closure of the dropdown after a selection is made.

## Components

### PalletGrid 

The PalletGrid is simple component that displays either the horizontal (PalletGridH) or vertical (PalletGridV) component depending on the `orientation` prop.

A simple JSX style ternary expression returns the correct variant.

Notice that string interpolation allows embedding the same Hyperscript code into both orientations.

```js title="PalletGrid.astro" "hs={hs}"  "orientation"
 ---
import PalletGridH from "/components/PalletGridH.astro"
import PalletGridV from "/components/PalletGridV.astro"

interface Props {
	orientation?:string
	hs?:string
}

const {orientation = "horizontal", hs} = Astro.props
---

<div >
	{orientation === 'horizontal' ? <PalletGridH hs={hs}/> : <PalletGridV hs={hs}/>}
</div>


```

### PalletItem

The essential component rendering a single swatch is the `PalletItem` comprised of a simple `<span>` whose background color is set using props. 

The PalletItem component accepts three props.   The `twColor prop is the name of the Tailwind color such as 'red-500'`.    The `hexCode` prop is the corresponding hexadecimal value for that color.  Finally, the `script` prop receives Hyperscript from its parent which is used to close the dropdown and then trigger some custom action.

A function in the component script capitalizes the first letter of the color name which is then used to set a `title` attribute creating a tooltip that will be displayed when the user hovers over the color swatch.

Since the swatch color is created using background colors, the 'bg-' prefix is stripped from the Tailwind class before the `title` string  is created.

Finally, a Hyperscript attribute on each `PalletItem` accepts a `script` prop which should listen for a click  and then send the `closeDropdown` custom event back to the parent `<button>`.  To make this happen, a `.colorPallet` class is explicitly added to the `<button>` of each dropdown component by passing this class name into the `buttonStyles` prop. The custom event should target the `.colorPallet` class in order to close the dropdown.

To set the background color of the swatch a simple string concatenation expression is used to combine the default styles with the `twColor` prop.   Since there are no default background colors, twMerge() is not needed here.

:::danger
Notice the space char between the variables composing the class list in the example code.  Since you are essentially concatenating strings to build the class list, leaving out this space character would concat two adjacent classes which breaks the styling."
:::

```js title="PalletItem.astro" "span" "twColor" "hexCode" "script"
---
interface Props {
	twColor: string  //a Tailwind bg-color class name
	hexCode:string  //corresponding hext code
	script?:string  //custom action when user selects a swatch
}

const {twColor, hexCode, script } = Astro.props

/* Palellets are built using the background color class names, so 
we strip out the 'bg' prefix and capitalize the first char to create
color family and shade names */
function capitalizeFirstCharacter(str) {
    if (!str) return str;
    return str.charAt(0).toUpperCase() + str.slice(1);
}

const color = capitalizeFirstCharacter(twColor.replace(/^bg-/, ''))

const tw = {
	palletItem: 'size-3 rounded-sm overflow-hidden ring-1 ring-slate-600 hover:scale-125',
}
---

<span 
	class={tw.palletItem + " " + twColor} title={`${color} (#${hexCode})`}
	bgcolor={twColor}
	script={script}>
</span>


```


## Code

Use the Tabs below to explore all the code used to create these examples.  

To apply  one of these palettes in your Astro project, copy and paste the code from either the Click or Hover activated examples into the Astro file where it will be used and then adjust the file import paths.  You will also need the parent dropdown components, either the [ClickDropdownMenu_A](/components/menus/click_a/) or [HoverDropdownMenu_B](/components/menus/hover_b/).

You will also need to copy and paste the PalletGrid, PalletGridH, PalletGridV, and  PalletItem code and put them into separate `.astro` files.

The import file paths in the sample code are for illustration purposes only and not specific for your project structure. Import paths will  need to be adjusted depending on where in your src folder you place the `.astro` files.

To give each swatch a custom action, provide your own  Hyperscript for the `hs` prop of the PalletGrid and this will be embedded into  the PalettItem component.

However, before your custom action is triggered, you should  `send closeDropdown to the .colorPallet then settle` to smoothly dismiss the dropdown before the user is taken away to something else.

interface Props {
	twColor: string  //a Tailwind bg-color class name
	hexCode:string  //corresponding hext code
	script?:string  //custom action when user selects a swatch
}

const {twColor, hexCode, script } = Astro.props

/* Palellets are built using the background color class names, so 
we strip out the 'bg' prefix and capitalize the first char to create
color family and shade names */
function capitalizeFirstCharacter(str) {
    if (!str) return str;
    return str.charAt(0).toUpperCase() + str.slice(1);
}

const color = capitalizeFirstCharacter(twColor.replace(/^bg-/, ''))

const tw = {
	palletItem: 'size-3 rounded-sm overflow-hidden ring-1 ring-slate-600 hover:scale-125',
}

	class={tw.palletItem + " " + twColor} title={`${color} (#${hexCode})`}
	bgcolor={twColor}
	script={script}>
