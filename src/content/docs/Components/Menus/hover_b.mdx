## Features

5. Uses Hyperscript [behaviors](https://hyperscript.org/features/behavior/) for showing and hiding dropdown 
1. Toggled by either `mouseenter` or `click`
2. Left and right slots for custom icons
3. Styling implemented entirely  with [Tailwind CSS](https://tailwindcss.com)
5. Dropdown dismissed by  item click, escape, or mouseleave
6. Menu items can invoke their own Hyperscripts

	```js "behavior ToggleDropdown" "behavior HideDropdown"
<script type="text/hyperscript">

behavior ToggleDropdown
	init
		set :dropdownContainer to my @id + '-container'
		set :itemsList to my @id + '-list'
		set :dropdownHasMouse to false
	end -- init

	on mouseenter from me
		call me.focus()
		trigger openDropdown on me
	end -- open on hover

	on mouseleave from me
		call me.blur()
		wait 50ms then
			if not :dropdownHasMouse trigger closeDropdown on me
		end
	end -- close after leaving button if menu is not hovered

	on click from me
		if I match .open then trigger closeDropdown on me
		otherwise trigger openDropdown on me
	end -- click toggles open/closed

	on mouseWithinDropdown(value)
		set :dropdownHasMouse to value
	end -- receives state from HideDropdown behavior

	on keydown[key=='Escape']
		trigger closeDropdown on me
	end -- keyboard dismissal

	def calculatedHeight
		set dropdownHeight to 0 then set items to the children of the #{:dropdownContainer}
		for item in items increment the dropdownHeight by the item's offsetHeight end
		return dropdownHeight
	end -- total dropdown height from rendered item heights

	def repositionDropdown
		set offsets to my @moveXY.split(',')
		set xOffset to the offsets[0] as Int
		set yOffset to the offsets[1] as Int
		measure me then put the result.bounds into buttonLocation
		set the *left of the #{:dropdownContainer} to (buttonLocation.left + xOffset + window.pageXOffset) px
		set the *top of the #{:dropdownContainer} to (buttonLocation.bottom + yOffset + window.pageYOffset) px
	end -- shift dropdown relative to trigger

	on openDropdown from me
		repositionDropdown()
		set the *height of the #{:dropdownContainer} to the calculatedHeight() px then wait 20ms then
		set the *opacity of the #{:itemsList} to 1
		add .open to me
	end -- open state

	on closeDropdown
		set the *opacity of the #{:itemsList} to 0
		set the *height of the #{:dropdownContainer} to 0 then settle then
		remove .open from me
	end -- close state
end -- behavior ToggleDropdown

behavior HideDropdown
	on mouseenter send mouseWithinDropdown(value:true) to the previous <button/> end
	on mouseleave send mouseWithinDropdown(value:false) to the previous <button/> end
	on click or mouseleave send closeDropdown to the previous <button/> end
end -- behavior HideDropdown

</script>
	```

## Transitions

[Hyperscript](https://hyperscript.org/) exposes `transition` for explicit CSS transitions in Hyperscript code. That path is [blocking](https://hyperscript.org/docs/#transitions), so you must call `settle` after each `transition` to let class swaps complete.

This component uses inline CSS `transition` rules instead, which keeps behavior code shorter and non-blocking.


## Slots

### Default Slot

Place menu items between the component tags so they render inside the internal `<ul>`.

### Icon Slots

Use `leftIcon` and `rightIcon` to pass custom icons or image markup.

In the example above, a down-caret SVG in `rightIcon` signals that the button reveals more choices.

### Icon Styling

In Astro, target a named slot by adding `slot="name"` to the parent element of the markup you pass in.

Apply Tailwind classes directly on slot markup because the receiving component cannot style unknown child elements.

```html title="Tailwind Styling for Icon Slots" "slot=\"rightIcon\"" "class=\"inline-block size-6\""
<svg slot="rightIcon" class="inline-block size-6" fill="currentColor" xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24">
	<path d="M7.41 8.59L12 13.17l4.59-4.58L18 10l-6 6-6-6z"/>
</svg>
```


## Usage

Import `HoverDropdownMenu_B` and render it as a custom tag, as shown in the example.

Attach custom behavior to each menu choice with a `script` attribute on each `<li>`.

Your custom menu scripts should generally include `send closeDropdown to the #{'hover_dropdown_id'} then settle` before follow-up actions so the menu closes cleanly.
