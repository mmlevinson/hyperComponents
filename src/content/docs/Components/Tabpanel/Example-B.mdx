## Features

1. Uses Hyperscript's `take` command to set `aria-selected` and `tabindex` attributes on the clickedTab
2. Switches tab appearance by setting `aria-selected = true` for the clickedTab
3. Avoids manually swapping active and inactive classes.
4. All functionality is delegated to the parent class ([TabPanel](#TabPanel_B) )
5. Preserves fetching hypermedia responses from API routes and smooth transitions using Hyperscript
6. Supports programmatic tab switching with `activateTabById`
7. Compatible with screen readers

This example is a direct port of the `aria-attribute`  example from the [Hyperscript Patterns](https://hyperscript.org/patterns/dom/tabs/) page illustrating the `take` command.

Tailwind supports the `aria-selected:` prefix which instructs the browser to apply those styles whenever an element has it's ` aria-selected = true`

Setting the `tab-index` to 0 keeps the focus on the clicked tab.

## Components

### TabPanel_B

All logic for switching the active and inactive styling is present in the parent TabPanel component.

The `aria-selected:` Tailwind styles are updated by the browser  when Hyperscript takes the `aria-selected = true` attribute from one tab and applies it to another

	<TabItem label='Scripts'>
	```js 'take'

const hs =
	`
	on init
		set :loadCount to 0
	end -- init

	-- logging reveals multiple load events ... debounce here
	on load
		if :loadCount is greater than 1 then exit end
		send activateTabById(tabId:'${defaultTabId}') to me
		increment :loadCount
	end -- load handler

	on click
		set clickedTab to the closest <[role=tab]/> to the target
		if no clickedTab exit end
		send activateTab(clickedTab:clickedTab) to me
	end -- click delegation

	on activateTabById(tabId)
		set requestedTab to #{tabId}
		if requestedTab exists
			send activateTab(clickedTab:requestedTab) to me
		end -- if
	end -- activate tab by id

	on activateTab(clickedTab)
		take @aria-selected='true' with 'false' from <[role=tab]/> in me for clickedTab
		take @tabindex='0' with -1 from <[role=tab]/> in me for clickedTab
		set output to the first <[role=tabpanel]/> in me
		if output exists
			set output's @aria-labelledby to clickedTab's @id
			set output's @aria-busy to 'true'
			set output's *opacity to 0
			fetch clickedTab's @data-path as html then put the result into output
			wait 50ms -- prevents intermittant quick flash of content without transition
			transition output's *opacity to 1 over 170ms
			set output's @aria-busy to 'false'
		end -- if
	end -- activate tab
	`
	```
	</TabItem>

## Usage

You can still switch tabs programmatically by sending `activateTabById` to the parent component.

```html title='Programmatic Tab Switch'
<button script="on click send activateTabById(tabId:'3') to the first <.tab-panel/>">
	Show Hyperscript tab
</button>
```
