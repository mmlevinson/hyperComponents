ReadMore components are useful for blogposts etc where a title and/subtitle introduces the content, but the user must click the Read More... link to reveal the full discussion.

Essentially, ReadMore components are very similar to Accordions, with a few differences:

1.  The Read More... link and twirl icon are presented after the title and introductory text
2.  When expanded, the `Read More ... `hint is swapped for an alternative hint (such as `Read Less ...`)

This hyperComponent modifies the code and layout from the [Accordion](/components/collapsables/accordion/) example.

### Features

1.  Built with two components ... [ReadMoreGroup](#readmoregroup) and [ReadMoreIte](#readmoreitem)

2.  [ReadMoreGroup](#readmoregroup) accepts multiple ReadMoreItems in it's default `<slot/>`

3.  [ReadMoreItem](#readmoreitem) accepts HTML into it's default `<slot/>`for both the title and introductory text

4.  The full content is pre-fetched from  the backend api route specified by the `path` prop when the user hovers over the Read More link

1.  Clicking any Read More ... link smoothly toggles the body content

2.  The `caption` (Read More ...) and `altCaption` (Read Less ...) can be customized via props

3.  The twirl icon can be customized by passing an icon image into the `<slot name='twirl-icon>'>` or by updating the default image in the component HTML

4.  A `maxHeight` prop prevents the body height from exceeding a set value and is adjusable per [ReadMoreItem](#readmoreitem)

5.  If the body content exceeds the `maxHeight`, a vertical scroll bar is applied

5.  If no maxHeight prop is sent, all of the content is displayed without a vertical scrollbar

1.  Baseline styling is exclusively by [Tailwind](https://tailwindcss.com)

5.  Add or override baseline styles by sending [Tailwind](https://tailwindcss.com) classes via props

2.  All actions (including transitions and content updating) performed by [Hyperscript](https://hyperscript.org) (No Javascript or frameworks)

The [Tailwind](https://tailwindcss.com) classes and Hyperscripts are both extracted from the markup and encapsulated into  Astro `tw` and `hs` local variables within the [Component Script](https://docs.astro.build/en/basics/astro-components/#the-component-script).
By using back-tick delimited strings, dynamic values can be passed into the [Hyperscript](https://hyperscript.org) code from outside of the component using props.

`twMerge()` allows custom styling via props while preventing [merge conflicts]('/about/tailwind/#merge-conflicts)

## Components

### ReadMoreGroup_A

This component provides a general `<ul>` wrapper around multiple ReadMoreItem_A components.  This wrapper then permits the developer to style the entire group, especially with positioning utility classes.  

In addition, Hyperscript in the group component listens for the `closeOtherReadMores` event and then optionally sends the closeUp event to all other ReadMoreItems according to the boolean `closeSiblings` prop.

### ReadMoreItem_A

The heart of this control is in the ReadMoreItem_A component.  This component provides a single `<li>` wrapper around both the introductory text and the hidden content.  

The introductory text is passed into the components default slot.  This strategy allows you to put any amount and any styling you wish into the introductory text. 

Hidden content is lazy-loaded using the fetch command in the accompanying Hyperscript.    `id` and `path` values are passed as props.  For this example, the `id` prop also serves the file `slug` which is concatenated to the `path` to build a valid route to the backend API endpoint and retrieve the correct hypermedia response. 

Review the Scripts tab in the [Code](#code) section below for the Hyperscript used to implement lazy-loading of the hidden content.


	A `style` attribute with transition timing function is added to the `div.body`.    When the script sets a new value to the height property of the div.body, this transition is triggered behind the scenes.

	```html "transition: all ${duration} ease-out"
<div  class={tw.body} style=`transition: all ${duration} ease-out`></div>	
	```

const hs = `

		def calcOpenHeight()
			set openHeight to 0
			set content to the children of the next .body
			for item in content 
				increment openHeight by the item's offsetHeight
			end
			increment openHeight by 25   -- for padding
			return openHeight 
		end -- calcOpenHeight 

		on mouseenter from me
			get the innerHTML of the next .body
			if it is empty then 
				fetch '${path}/${id}' as html then put the result into the next .body
		end -- mouseenter handler

		on click from me
			measure the next .body
			if the result.height is greater than 0 then send collapse to me
			otherwise send expand to me end
		end -- click handler

		on expand
			set my textContent to '${altCaption}'
			add .rotate-180 to the  #{'twirl-icon-'+${id}}
			set openHeight to calcOpenHeight()
			if openHeight is greater than ${maxHeight} then
				add .overflow-y-scroll to the next .body
				set the *height of the next .body to ${maxHeight} px then settle
			otherwise
				set the *height of the next .body to the openHeight px then settle
			end
		end -- expand event handler

		on collapse
			set my textContent to '${caption}'
			remove .rotate-180 from the  #{'twirl-icon-'+${id}}
			remove .overflow-y-scroll from the next .body
			set the *height of the next .body to 0 then settle		
		end -- collapse event handler
`

##  Usage
	{/* Discuss use cases */}	

The most common use case for ReadMore controls is on blog sites.    Each blog post is introduced by a short title section, including a summary, author, and posting date.    Clicking the Read More... caption activates the transition to expose the full content of the blog post.    FAQs and other stacked article formats can also make use of the ReadMore control.
