### Features

1.  Built with two components ... [AccordionGroup](#accordiongroup) and [AccordionItem](#accordionitem)

2.  [AccordionGroup](#accordiongroup) accepts multiple AccordionItems in it's default `<slot/>`

3.  [AccordionItem](#accordionitem) accepts HTML into it's default `<slot/>`, or preferably by fetching hypermedia from an api route specified in the optional `path` prop

1.  Clicking any header smoothly toggles the body content

4.  Collapse and expand durations can be different

2.  An optional `closeSiblings` prop signals the parent component to close all other items

4.  A `maxHeight` prop prevents the body height from exceeding a set value and is adjusable per [AccordionItem](#accordionitem)

5.  If no maxHeight prop is sent, accordion body expands to fit the content height (no vertical scroll bars shown)

1.  Baseline styling is exclusively by [Tailwind](https://tailwindcss.com)

5.  Add  or override baseline styles, including the active state, by sending [Tailwind](https://tailwindcss.com) classes via props

2.  All actions (including transitions and content updating) performed by [Hyperscript](https://hyperscript.org) (No Javascript or frameworks)

The [Tailwind](https://tailwindcss.com) classes and Hyperscripts are both extracted from the markup and encapsulated into  Astro `tw` and `hs` local variables within the [Component Script](https://docs.astro.build/en/basics/astro-components/#the-component-script).
By using back-tick delimited strings, dynamic values can be passed into the [Hyperscript](https://hyperscript.org) code from outside of the component using props.

`twMerge()` allows custom styling via props while preventing [merge conflicts]('/about/tailwind/#merge-conflicts)

### Components

#### AccordionGroup

This is the parent (or wrapper) component.  The default `<slot/>` accepts multiple [AccordionItem](#accordionitem) components as in the example above.

If the `closeSiblings` prop is set to `{true}` then only one [AccordionItem](#accordionitem) can be expanded and all others receive a `collapse` event.

The `styles` prop is used to to override or add  [Tailwind](https://tailwindcss.com) classes  to customize the AccordionGroup's  appearance.

### AccordionItem

Content displayed by each item can be installed in two ways:

1. Placing HTML direclty into the AccordionItem's  default `<slot>`, or
2. Providing an api route in the optional `path` prop

If you want to hard code content,  use option 1 above.  However, it is best practice to establish an api which can fill the item with dynamic  on demand.

The header displays a caption, and optional prefix character ('-' in the example).  Clicking the  header toggles visibility of the body using a transition which can be adjusted using props.

You can set separate transition durations for the `expand` or `collapse` events.

You can replace the twirl icon with any SVG you like in the HTML markup below.  Make sure you retain the `id` as in the example so [Hyperscript](https://hyperscript.org) identifies the correct element to rotate.
  

	
<Tabs>
	<TabItem label='Props'>
	```js

	interface Props {
		id:string,   //a unique identifier allowing multiple AccordionItems on a page without collisions
		caption:string,   //the text display in the Accordion header
		prefix?:string   //a tick mark preceeding the caption
		maxHeight:string  //maximum open height in px (after which the body content scrolls vertically)
		headerStyles?:string   //override or add TW classes to the header
		bodyStyles?:string   //override or add TW classes to the body
		activeHeaderStyles?:string //override, add, remove TW classes for headers of opened Accordions
		openDuration?:string   //transition timing when showing body content
		closeDuration?:string  //transition timing when hiding body content
		path?:string //an optional api endpoint to fetch hypermedia for accordion body
		}

	const {
		id, 
		caption, 
		prefix='- ',
		maxHeight,
		headerStyles,
		bodyStyles,
		activeHeaderStyles = 'bg-orange-100 dark:bg-indigo-950',
		openDuration='260ms',
		closeDuration='400ms',
		path
	} = Astro.props
		 
	```

	```js
const hs = `
		init
			set :accordionOpen to false
			set :accordionBody to my @id + '-body'
			set :twirlIcon to my @id + '-twirl-icon'
		end -- init

		def calcBodyHeight()
			set bodyHeight to 0
			set accordionContent to the children of the #{:accordionBody}
			for item in accordionContent 
				increment bodyHeight by the item's offsetHeight
			end -- for
			increment bodyHeight by 45   -- for .py-4 when accordion open
			return bodyHeight 
		end

		on click from me
			if :accordionOpen is true then trigger collapse on me
			otherwise trigger expand on me
			end 
		end -- click

		on expand
			add ${activeStyles} to me
			add .py-4 .border-t-2 to the  #{:accordionBody}
			fetch '${path}' as html then put the result into #${id}-body
			set bodyHeight to calcBodyHeight()
			if the bodyHeight is greater than ${maxHeight}
				transition the  *height of #{:accordionBody} to ${maxHeight} px using 'all ${openDuration} ease-in'
				add .overflow-y-auto to the #{:accordionBody}
			otherwise
				transition the *height of #{:accordionBody} to bodyHeight px using 'all ${openDuration} ease-in'
			end -- if > maxHeight
			add .rotate-180 to the #{:twirlIcon}
			set :accordionOpen to true
			send collapseSiblings to the closest <ul/>
		end -- expand

		on collapse
			remove ${activeStyles} from me
			remove .py-4 .border-t-2 .overflow-y-auto from the #{:accordionBody}
			remove .rotate-180 from the #{:twirlIcon}
			transition the *height of #{:accordionBody} to 0 using 'all ${closeDuration} ease-out'
			set :accordionOpen to false
		end -- collapse
	`


	```

##  Usage

Accordion controls are often used in FAQ or Info sections of a website.  The advantages of using an Accordion are to hide the majority of the content until the user needs to see it.  

To include these components in your project, just copy the Everything tab for both the [AccordionGroup](#accordiongroup) and [AccordionItem](#accordionitem) components and place into separate files in your Astro project.

The example above illustrates embedding multiple [AccordionItems](#accordionitem) into the default `<slot/>` of the [AccordionGroup](#accordiongroup) and using the `path` prop to fetch content.
