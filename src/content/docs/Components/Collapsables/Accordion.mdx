### Features

1.  Built with two components ... [AccordionGroup](#accordiongroup) and [AccordionItem](#accordionitem)

2.  [AccordionGroup](#accordiongroup) accepts multiple [AccordionItem](#accordionitem)s in it's default `<slot/>`

3.  [AccordionItem](#accordionitem) accepts either raw HTML into it's default `<slot/>`, or preferably by a `path` prop to fetch content from an api endpoint

1.  Clicking any header smoothly toggles the body content

4.  Collapse and expand durations can be different

2.  An optional `closeSiblings` prop signals the parent component to collapse all other items

4.  A `maxHeight` prop prevents the body height from exceeding a set value and is adjusable per [AccordionItem](#accordionitem)

5.  Any content that exceeds the `maxHeight` gets vertical scroll bars

5.  If no maxHeight prop is sent, [AccordionItem](#accordionitem) expands to fit the content height (no vertical scroll bars shown)

1.  Baseline styling is exclusively by [Tailwind](https://tailwindcss.com)

5.  Add  or override baseline styles, including the active state, by sending [Tailwind](https://tailwindcss.com) classes via props

2.  All actions (including transitions and data fetching) performed by [Hyperscript](https://hyperscript.org) (No Javascript or frameworks)


The [Tailwind](https://tailwindcss.com) classes and Hyperscripts are both extracted from the markup and encapsulated into  Astro `tw` and `hs` local variables within the [Component Script](https://docs.astro.build/en/basics/astro-components/#the-component-script).
By using back-tick delimited strings, dynamic values can be passed into the [Hyperscript](https://hyperscript.org) code from outside of the component using props.

`twMerge()` allows custom styling via props while preventing [merge conflicts]('/about/tailwind/#merge-conflicts)

### Components

#### AccordionGroup

This is the parent (or wrapper) component.  The default `<slot/>` accepts multiple [AccordionItem](#accordionitem) components.

If the `closeSiblings` prop is set to `{true}` then only one [AccordionItem](#accordionitem) can be expanded and all others receive a `collapse` event.

The `styles` prop is used to to override or add  [Tailwind](https://tailwindcss.com) classes  to customize the AccordionGroup's  appearance.

#### AccordionItem

Content displayed by each item can be installed in two ways:

1. Placing HTML direclty into the AccordionItem's  default `<slot>`, or
2. Providing an api route in the optional `path` prop

If you want to hard code content,  use option 1 above.  However, it is best practice to establish an api which can fill the item with dynamic content on demand.

The header displays a caption, and optional prefix character ('-' in the example).  Clicking the  header toggles visibility of the body using a transition which can be adjusted using props.

You can customize the speed of both  the `expand` or `collapse` actions using the `collapseDuration` and/or `expandDuration` props

You can replace the twirl icon with any SVG you like in the HTML markup below.  Make sure you retain the `id` as in the example so [Hyperscript](https://hyperscript.org) identifies the correct element to rotate.
  
The vertical height of the expanded AccordionItem can be clamped using the `maxHeight` prop.   Any content taller than the `maxHeight` will automatically receive a vertical scrollbar.

Custom styling is passed into the AccordionItem using the following props:

1.  `headerStyles` ... override/add TW classes to the inactive header
2.  `bodyStyles` ... override/add TW classes to the body container
3.  `activeHeaderStyles` ... customize appearance of the header for the expanded AccordionItem

	```js "script={hs}" "twMerge" "${path}"
import {twMerge} from 'tailwind-merge'

interface Props {
		id:string,   //a unique identifier allowing multiple AccordionItems on a page without collisions
		caption:string,   //the text display in the Accordion header
		prefix?:string   //a tick mark preceeding the caption
		maxHeight:string  //maximum open height in px (after which the body content scrolls vertically)
		headerStyles?:string   //override or add TW classes to the header
		bodyStyles?:string   //override or add TW classes to the body
		activeHeaderStyles?:string //override, add, remove TW classes for headers of opened Accordions
		expandDuration?:string   //transition timing when showing body content
		collapseDuration?:string  //transition timing when hiding body content
		path?:string //an optional api endpoint to fetch hypermedia for accordion body
	}

const {
	id, 
		caption, 
		prefix='- ',
		maxHeight,
		headerStyles,
		bodyStyles,
		activeHeaderStyles = 'bg-orange-100 dark:bg-indigo-800',
		expandDuration='400ms',
		collapseDuration='150ms',
		path
} = Astro.props

const tw = {
	wrapper:'shadow-lg overflow-hidden ' + 
	'border-4 border-b-0 last-of-type:border-b-4 border-indigo-500 border-opacity-20  dark:border-gray-700 ' + 
	'first-of-type:rounded-t-xl last-of-type:rounded-b-xl',
	accordionHeader: twMerge('w-full flex justify-between items-center p-3 select-none cursor-pointer ' +
		'font-bold text-lg text-left text-gray-900 dark:text-zinc-300 ' +
		'bg-blue-100 hover:bg-sky-950 hover:text-yellow-50 ' +
		'dark:bg-slate-900 dark:hover:bg-purple-950 dark:hover:text-fuchsia-100 ' + 
		'', headerStyles),
	accordionBody: twMerge('hidden h-0 px-6 text-left border-zinc-600 ' + 
		' bg-gray-100 text-slate-800 dark:bg-gray-900 dark:text-gray-100 overflow-y-hidden ', bodyStyles),
	icon: 'size-6 shrink-0'
}

//Using TW styles in Hyperscript code requires a preceeding dot char for the HS parser
function formatTWClasses(twClasses) {
    return twClasses.split(' ').map(twClass => '.' + twClass).join(' ');
}

const activeStyles = formatTWClasses(activeHeaderStyles)

const hs = `
	init
		set :accordionBody to 'body-' + my @id
		set :twirlIcon to 'twirl-icon-' + my @id
	end -- init

	-- check for an api endpoint and then pre-fetch lastest content
	on mouseenter from me
		if '${path}' exists fetch '${path}' as html then put the result into the #{:accordionBody}
	end -- preload handler

	-- calculate the vertical height of all body content
	def calcOpenHeight()
		set openHeight to 0
		set content to the children of the #{:accordionBody}
		for item in content 
			increment openHeight by the item's offsetHeight
		end -- for
		increment openHeight by 45   -- for .py-4 when accordion open
		return openHeight 
	end

	on click from me
		if the #{:accordionBody} matches .hidden then send expand to me
		otherwise send collapse to me end
	end -- click

	on expand
		add ${activeStyles} to me
		remove .hidden from the #{:accordionBody}
		set openHeight to calcOpenHeight()
		if openHeight is greater than ${maxHeight}
			add .overflow-y-scroll to the #{:accordionBody} 
			transition the *height of #{:accordionBody} to ${maxHeight} px using 'all ${expandDuration} ease-in' 
		otherwise
			transition the *height of #{:accordionBody} to openHeight px using 'all ${expandDuration} ease-in'
		end -- if > maxHeight
		add .rotate-180 to the #{:twirlIcon}
		send collapseSiblings to the closest <ul/>   -- the parent AccordionGroup
	end -- expand

	on collapse
		remove .rotate-180 from the #{:twirlIcon}
		remove ${activeStyles} from me
		transition the *height of #{:accordionBody} to 0 using 'all ${collapseDuration} ease-out'
		remove .overflow-y-scroll from the #{:accordionBody}
		add .hidden to the #{:accordionBody}
	end -- collapse
`
---
<li class={tw.wrapper}>
	<!-- Accordion Header -->
	<button id={id} class={tw.accordionHeader} script={hs}>
			<!-- (Prefix) Caption -->
			<span>{prefix}{caption}</span>
			<!-- TwirlIcon -->
		<svg id={`twirl-icon-${id}`} class={tw.icon} fill='currentColor' viewBox='0 0 20 20' xmlns='http://www.w3.org/2000/svg'>
				<path fill-rule='evenodd' d='M5.293 7.293a1 1 0 011.414 0L10 10.586l3.293-3.293a1 1 0 111.414 1.414l-4 4a1 1 0 01-1.414 0l-4-4a1 1 0 010-1.414z' clip-rule='evenodd'></path>
			</svg>
	</button>

	<!-- Accordion Body -->
	<div 	id={`body-${id}`} class={tw.accordionBody}>
		<!-- Default Slot (for multiple AccordionItems) -->
		<slot/>
	</div>

</li> 
	```
	</TabItem>

##  Usage

Accordion controls are often used in FAQ or Info sections of a website.  The advantages of using an Accordion are to hide the majority of the content until the user needs to see it.  

To include these components in your project, just copy the Everything tab for both the [AccordionGroup](#accordiongroup) and [AccordionItem](#accordionitem) components and place into separate files in your Astro project.

The example above illustrates embedding multiple [AccordionItems](#accordionitem) into the default `<slot/>` of the [AccordionGroup](#accordiongroup) and using the `path` prop to fetch content.
